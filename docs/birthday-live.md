# 11/4 バースデーライブ

makoto2 の**実質的な締め切り**であり、作り直しのゴール。

## 位置づけ

**11/4 は MAKOTO の誕生日という設定**（モデルの剣崎真琴＝キュアソードと同じ日）。以前は「バースデーライブ」と銘打ち、少しストーリー性を持たせて頻度を上げて投稿させていた。**どうにかこれはやらせたい**という要件。

- **11/1 から予告を始める**＝機能的な締め切りは 11/4 ではなく **11/1**
- **2026-11-04 は水曜、11/1 は日曜**（ニチアサ実況の日＝サーバーが最も賑わう日）

## 2024 年の台本（時刻は JST）

| 時刻 | 投稿 |
| --- | --- |
| 12:00 | 「剣崎真琴バースデーライブ **SONGBIRD PARTY 2024** スタートです！ **20:00 まで歌い続けます**。聴きたくない方はミュートしてくださいね」 |
| 〜20:00 | 曲を歌い続ける |
| 20:00 | 「これでおしまいです。最後まで聴いてくれてありがとう。**また来年、会いに来てね**」 |

**開始と終了の告知で挟んだ 8 時間の枠**という構造。前日（11/3）も投稿を増量して助走をつけている。

## ライブ名の出所

artistId **666611184 =「キュアソード/剣崎真琴(CV:宮本佳那子)」の 8 曲がすべて「ドキドキ!プリキュア キャラクターアルバム 〜SONGBIRD〜」**（2013-05-29）に収録されている。**「SONGBIRD PARTY」はこのキャラクターアルバムが由来**で、この 8 曲が中核のセットリストにあたる。

## 必要なもの

- **曲データ** — 旧 DB の `track` テーブルは 0 件で歌う中身が残っていない。iTunes Search API から自動収集する方式を実証済み（→ [track-corpus.md](track-corpus.md)）。**ライブ用 234 曲のうち vocal が 194 曲**あり、8 時間を重複なしで回せる量
- **投稿スケジューラ** — 12:00 開始 / 20:00 終了の固定枠と、その間の配信ペース
- **原稿の上書き** — 開始・終了の告知は前もって用意した原稿を使う。旧 `message` テーブルの `birthday` type（23 件）と `month`/`day` 列がこの用途（→ [makoto-legacy.md](makoto-legacy.md)）
